# Tegami

Speak freely. 言葉は、自由だ。

現在、ベータ版を開発中です。

このメッセージアプリ「Tegami」は2つの特徴があります。
それは「自由」と「AIフレンドリー」です。

まずは「自由」について。2026年、世の中には無数のメッセージアプリが存在しますが、どれも自由とは程遠いです。資本主義によって完成されたシステムによって、ユーザーに不必要な情報を押し付けてきます。広告、ニュース、買い物、頼んでもないおすすめばかりです。無理やり奪われた私たちの個人情報は、企業に売られ、その費用は消費者に転嫁されていきます。メッセージアプリを使いたいだけなのに、マーケティングの道具として利用されてしまうのです。それは「不自由」だと思いました。私たちは「自由」なメッセージアプリを開発します。

つぎに「AIフレンドリー」について。あなたのメッセージアプリにも訳のわからないAIが搭載されていませんか？不思議な制限がついた、程度の低い営利目的のAIと連携させられているかと思います。私たちは普段利用しているAIエージェントと連携できる、「AIフレンドリー」なメッセージアプリを開発します。
