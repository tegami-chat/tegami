This page is for people who know Nostr and want to check which parts of it Tegami uses and which it does not.

## How it differs from a Nostr client

Tegami is a messaging app built on the Nostr protocol, but it is not a Nostr client in the social-network sense. Accounts use Nostr keys (secp256k1) and messages are sent and received in the NIP-17 format. Tegami never publishes public posts (kind 1) or a public profile (kind 0).

## Messaging with other Nostr apps

Tegami cannot message people on other Nostr apps today. The Tegami app connects only to its own relay (`wss://relay.tegami.chat`), and that relay only accepts [envelopes](/developers/architecture/#envelopes) from connections logged in with a key registered with Tegami.

We keep it closed so spam and impersonation are stopped at the door. On the relay side we have registration control, sending limits, reports, and the ability for us to suspend keys. The cost is that Tegami does not offer one of Nostr's core strengths: using the same key in any app.

We are comparing three options:

- <Badge text="Under discussion" variant="caution" /> Letting you add a company or school relay as an inbox
- <Badge text="Under discussion" variant="caution" /> Showing messages from other Nostr apps
- <Badge text="Under discussion" variant="caution" /> Listing in an official directory only relays that agree to Tegami's rules

We have not picked one yet.

## What Tegami uses and does not use

| Nostr feature | In Tegami |
| --- | --- |
| Account = secp256k1 key pair (npub and nsec) | Used. No phone number or email address |
| Event format (id, pubkey, created\_at, kind, tags, content, sig) and Schnorr signatures | Used. Messages, relay login, and signatures for HTTP endpoints all use this format |
| Relays (servers that store and deliver events over WebSocket) | Used. But only one Tegami-only relay, not public relays |
| Encrypted DMs (NIP-17, NIP-44, NIP-59) | Used. The foundation of messaging |
| Public posts (kind 1), follows (kind 3), timelines | Not used. No social-network features |
| Public profile (kind 0) | Not used. Your name is passed in the invite link, and your icon is delivered encrypted to friends only |
| Published relay lists (NIP-65 kind 10002, NIP-17 kind 10050) | Not used. The app connects only to the Tegami relay |
| Zaps (Bitcoin tips) | Not used in the app. Supported only for receiving on the official account |
| Legacy DMs (NIP-04) | Not used. They expose sender and recipient to the relay |

In short, Tegami uses Nostr as a way to "prove identity with a key and leave signed envelopes with a relay," and leaves out the social-network parts.

- <Badge text="Under discussion" variant="caution" /> We want people to be able to send money freely with Bitcoin. We have not decided whether to build Zaps into the app.

## NIPs in use

Messages use NIP-17 and NIP-59, encrypted with NIP-44. Relay login uses [NIP-42](/developers/spec/#glossary), expiring events use NIP-40, and HTTP signatures use [NIP-98](/developers/spec/#glossary). NIP-05 is used for the official account and NIP-11 for relay info. Photos and files are stored the [Blossom](/developers/spec/#glossary) way. Tegami does not use public posts (kind 1) or public profiles (kind 0). The full list is in the [technical spec](/developers/spec/).
