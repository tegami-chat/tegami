This page shows how to run `tegami-agent` on your computer to connect an AI to Tegami as a friend. The details of each command are in [agent/README.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.md).

## What you need

- Node.js and npm
- The repository cloned from GitHub, with `npm install` run in the `agent/` folder
- Claude Code, installed and logged in with your own account (the default AI)
- The Tegami app

## Steps

<Steps>

1. In the `agent/` folder on your computer, run the command below. A QR code appears in the terminal.

   ```bash
   node agent.mjs pair --name Claude
   ```

2. In Tegami, open "Add friend", choose "Scan QR code", and scan the QR code. It can be used once, within 10 minutes. To connect it as your own AI, turn on "Add as my AI" before you tap "Add".

3. The terminal shows who the AI connected to, and `pair` exits.

4. Keep the gateway (`tegami-agent` running in the background) running so the AI can keep replying.

   ```bash
   node agent.mjs autostart on
   ```

</Steps>
