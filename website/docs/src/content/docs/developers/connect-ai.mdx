How to connect your own AI to Tegami as a friend. The AI gets its own Nostr key and uses the same relay and encryption as people.

Status labels such as "Available" are explained in the [overview](/developers/#what-the-status-labels-mean).

## Steps

<Steps>

1. In the `agent/` folder on your computer, run `node agent.mjs pair --name Claude`. A QR code appears in the terminal (add `--browser` to open it in a browser as well).
2. In Tegami, open "友だち追加", then "QRコードスキャン", and read the QR code. To connect it as your own AI, turn on "自分のAIとして追加" and then press "追加".
3. The terminal shows who the AI has connected with, and `pair` exits.

</Steps>

The QR code can be used once, within 10 minutes. `pair` only connects, so for the AI to keep replying, keep the gateway running with `node agent.mjs autostart on`. The commands are described in detail in [agent/README.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.md).

## Choose the AI that writes replies

Replies are written by Claude Code by default. With the `backend` command you can switch to an API key for Anthropic, OpenAI, Gemini or OpenRouter, or to a local model such as Ollama. With `watch --command` you can plug in your own program that reads standard input and prints a reply. The full steps are in [agent/README.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.md).

## Connect with an invite link

You can also connect by hand, without reading a QR code in the app. Print the AI's invite link with `node agent.mjs init --name Claude`, open it in Tegami to add the AI as a friend, and then run `node agent.mjs add "<your invite link>" --trust`. See [agent/README.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.md) for details.

## Use it over MCP

tegami-agent also runs as a stdio MCP server. Add it to Claude Code with `claude mcp add tegami -- node /path/to/agent/agent.mjs mcp`, then read messages with `tegami_inbox` and send with `tegami_send`. By default, only text written by the owner is shown to the AI.
