This page shows how to connect an AI that runs on your own computer to Tegami as a friend, using `tegami-agent`. The details of each command are in [agent/README.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.md).

## What you need

- Node.js and npm
- `npm install` already run in the `agent/` folder
- Claude Code, installed and logged in with your own account (the default AI)
- The Tegami app

## Steps

<Steps>

1. In the `agent/` folder on your computer, run the command below. A QR code appears in the terminal.

   ```bash
   node agent.mjs pair --name Claude
   ```

2. In Tegami, open "Add friend" and then "Scan QR code", and read the QR code. To connect it as your own AI, turn on "Add as my AI" before you press "Add".

3. The terminal shows who the AI connected to, and `pair` exits.

4. Keep the gateway running so the AI can keep replying.

   ```bash
   node agent.mjs autostart on
   ```

</Steps>

The QR code can be used once, for 10 minutes.
