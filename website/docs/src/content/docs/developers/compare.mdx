This page is for developers who want to compare Tegami with other messaging apps. Tables show how it differs from LINE, WhatsApp, Signal and Telegram, and from other Nostr apps. The Tegami column reflects what runs in production today.

## How it differs from LINE, WhatsApp, Signal and Telegram

|  | LINE | WhatsApp | Signal | Telegram | Tegami |
| --- | --- | --- | --- | --- | --- |
| What you need to start | A phone number | A phone number | A phone number (a username only keeps your number from showing to others) | A phone number (you can also buy a Telegram-only number) | Nothing. The device makes a key |
| End-to-end encryption | Default for one-to-one and groups (Letter Sealing). Group calls are encrypted only on the network path | Default | Default | Regular chats can be opened on the operator's servers. End-to-end encryption is only for one-to-one "Secret Chats" | Default for one-to-one and groups (NIP-17) |
| Forward secrecy | Letter Sealing does not support it | Yes (uses the Signal Protocol) | Yes (Double Ratchet, PQXDH) | Secret Chats only | No |
| Metadata the operator can see | States that it records who you talk to and when on its servers | States that it collects connection and usage information | Only the minimum needed to run. Has a way to hide the sender (Sealed Sender) | States that it may keep IP addresses and similar for up to 12 months | Recipient, time, size, connected keys, IP address. When it accepts an envelope it also knows the sender's key, but does not store it |
| Ads | Shown at the top of the chat list | Shown in the updates screen (Status and Channels). States that personal chats are not used for ads | None. Runs on donations | Shown in public channels with more than 1000 subscribers | None |
| AI | The operator's AI (Agent i). Using it lets LINE Yahoo collect up to 300 messages of that chat | The operator's AI (Meta AI) | Not found in official documents | Summaries by the operator's AI, and bots anyone can make | No operator AI. Your own computer's AI appears as a friend |
| Operator | LINE Yahoo (the company half owned by SoftBank and NAVER holds 62.4% of the voting rights) | Meta | A US nonprofit | Telegram Messenger Inc. | An individual in Japan |
| Code published | Neither the app nor the server was found | Not checked | App and server both AGPL-3.0 | App is published. Server is not | App and relay both AGPL-3.0 |

Checked on: November 16, 2026. We read each company's official documentation.

On the strength of encryption alone, Signal's design is stronger than Tegami's. Where Tegami differs is that it needs no phone number, has no ads or operator AI, lets you place your own AI as a friend, and publishes the code down to the server side (of the four, only Signal also publishes its server).

## How it differs from 0xchat

0xchat is an app with almost every Nostr chat feature, and it points in a different direction from Tegami.

|  | 0xchat | Tegami |
| --- | --- | --- |
| Who you can reach | Anyone on Nostr. Uses public relays (damus, nos.lol and others), and the operator's own relay is closed | Only people registered with Tegami. A dedicated relay |
| Storing the secret key | Encrypts it with a password the app made, and puts that password in the same row of the same database, and opens it automatically at startup. App lock (biometrics, PIN) is separate | Encrypts it with the passkey PRF and asks for passkey authentication each time you open it (where PRF is unsupported, it encrypts with a key inside the device) |
| External signers | Supports NIP-46 and NIP-55 (Amber and others) | Not supported |
| Exporting the key | You can show and copy the nsec in settings | Not possible |
| If you lose the key | We found no way to leave a backup. You are expected to keep the nsec yourself | You can restore with the recovery code |
| AI | Translation only (on the device or with LibreTranslate). We found no AI bot or MCP in the code | Your own computer's AI appears as a friend. Supports MCP. You set in the app what the AI is allowed |
| Groups | NIP-17 groups, NIP-28 channels, NIP-29 relay groups. MLS is supported in its sister app XChat | NIP-17 groups only |
| Calls | WebRTC by NIP-100. The user sets the relay server | WebRTC with signaling in [envelopes](/developers/architecture/#envelopes). You can use Cloudflare's relay server (TURN), or set up your own |
| Devices | Apps for iPhone, Android, Windows, Mac and Linux. We found no browser version | The browser version is <Badge text="Available" variant="success" />. The Android app is a prototype and <Badge text="Coming soon" variant="tip" />. iPhone, Windows, Mac and Linux are <Badge text="Planned" variant="default" /> |
| Other | Built-in Tor, a Cashu wallet, Zaps and translation | Registration by invite ticket or human check (Turnstile), and key suspension by the operator |

Checked on: November 16, 2026. We checked against the code of 0xchat's public repository (`0xchat-app/0xchat-app-main`).

0xchat is an app for people who already use Nostr, and Tegami is an app for people who want to leave LINE without knowing Nostr. 0xchat is ahead in being open to the Nostr world and in how finely you can set things yourself.

<Aside type="caution" title="What Tegami lacks, and what we could not fully check">

Tegami has no external signer, no key export, and no store app.

We could not fully check whether 0xchat's whole database is encrypted (it does have a screen to enter a database passphrase).

</Aside>

- <Badge text="Coming soon" variant="tip" /> The Android app is a prototype (it runs on an emulator as far as the chat list).
- <Badge text="Planned" variant="default" /> We will offer apps for iPhone, Windows, Mac and Linux.
- <Badge text="Under discussion" variant="caution" /> External signing (NIP-46), and how to connect with other Nostr apps.

## How it differs from White Noise

White Noise is a messaging app that uses MLS on Nostr, and it also has a way to talk to an AI running on your own computer as a contact, and multiple profiles. As an encryption method, it is stronger than Tegami's NIP-17 because it has forward secrecy. Where Tegami differs is that it protects keys with a passkey, has calls, has registration and reporting on a dedicated relay, and lets you decide in finer detail inside the app what the AI is allowed. On the strength of the encryption method, Tegami does not match White Noise.

Checked on: November 13, 2026. The words passkey, calls and MCP did not appear in White Noise's official documents.

## What only Tegami has

Each feature on its own exists in other apps. What Tegami aims for is the combination. It is for people who want to leave LINE but do not know Nostr: they can start with just a passkey and no password, place family and their own AI in the same chat list, and use it in a place protected from junk messages.

- <Badge text="Decided" variant="note" /> We aim for an app people choose not because "it has this feature" but because they think "I send messages with Tegami by default".
