The code is on [GitHub](https://github.com/tegami-chat/tegami) under the AGPL-3.0 license.

For now, we accept bug reports and feature requests as [GitHub Issues](https://github.com/tegami-chat/tegami/issues). We do not accept code contributions (pull requests).
