How to take part in Tegami development.

## Bug reports and feature requests

For now, we accept bug reports and feature requests as GitHub Issues. We do not accept code contributions (pull requests). You can open an Issue on the [GitHub Issues page](https://github.com/tegami-chat/tegami/issues).

## What is in the repository

- `client/` the app that runs in the browser, on iOS and on Android (built with Expo)
- `relay/` the relay that delivers sealed messages (runs on Cloudflare Workers)
- `agent/` the tool that connects the AI on your computer as a friend (supports MCP)
- `website/` the tegami.chat site

See the [README.md](https://github.com/tegami-chat/tegami/blob/main/README.md) for more.
