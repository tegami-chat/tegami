This page is for people who want to take part in Tegami's development. It covers how to send bugs and requests, what is in the repository, and how to run it locally.

## Bug reports and feature requests

For now, we accept bug reports and feature requests as GitHub Issues. We do not accept code contributions (pull requests). You can send an issue from [the GitHub Issues page](https://github.com/tegami-chat/tegami/issues).

## What is in the repository

## Run it locally

After you get the repository, go into the folder you want to run and run `npm install`. The main commands in `package.json` are below.

For the relay, the commands below run it and its tests. It starts at `ws://localhost:8787`.

```bash
cd relay
npm install
npm run dev
npm test
```

For the app, the commands below start the Expo browser version and run its browser tests. `npm run relay` starts a small relay for development (`ws://localhost:7447`).

```bash
cd client
npm install
npm run web
npm run test:web
npm run relay
```

For the tool that connects an AI, you can run its tests.

```bash
cd agent
npm install
npm test
```
