Tegami is an open-source messaging app built on Nostr. The sending device seals each message before leaving it with the relay, so the server cannot read it. The AI runs on your own computer and talks in the same format as human friends.

These docs are for people who want to check how Tegami is built. They say what runs in production today, what is still missing, and what comes next. Production is described as of November 18, 2026, in [tegami-chat/tegami](https://github.com/tegami-chat/tegami).

## Where the code lives

The code is split into `client/` (the app), `relay/` (the relay), `agent/` (the tool that connects an AI) and `website/` (the site). The full list of folders is in [Contributing](/developers/contributing/#what-is-in-the-repository).

## Open source

Tegami is licensed under AGPL-3.0. Anyone who offers an app built from Tegami's code over a network must also publish their code.

For now, we accept bug reports and feature requests as GitHub Issues. We do not accept code contributions (pull requests). To take part in development, see [Contributing](/developers/contributing/).
