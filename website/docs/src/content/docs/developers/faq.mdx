Common questions from developers about how Tegami is built. Describes production as of November 18, 2026.

## Can I run my own relay?

Yes. The relay code is public in `relay/`. The current app only connects to the official relay, so to use your own you need to build the app yourself. The steps are in [Run your own relay](/developers/self-host-relay/).

## Can I message people on other Nostr apps?

Not yet. The Tegami relay only accepts writes from connections logged in with a key registered with Tegami. See [Nostr](/developers/nostr/) for details.

## Which NIPs does Tegami use?

Messages use NIP-17 and NIP-59, encrypted with NIP-44. The list of NIPs in use is in the [technical spec](/developers/spec/).

## What encryption do you use? Is there forward secrecy?

Messages are encrypted with NIP-44 v2 and double-wrapped in the NIP-59 way. There is no forward secrecy. See [Encryption](/developers/encryption/) and the [technical spec](/developers/spec/).

## How is my secret key protected? Can I use my existing nsec?

The Nostr secret key is encrypted with a value taken from the passkey PRF extension, and only the ciphertext is stored on the device. You can't log in with an existing nsec or export your key. See [Keys](/developers/keys/).

## What can the relay see?

The recipient's public key on each gift wrap, the time it arrived, its size, and the logged-in keys with their IP addresses. It cannot read the message. See [Encryption](/developers/encryption/).

## Can I verify that production matches the public code?

Not yet. The commit the relay reports is only our own claim, and the browser app has no reproducible builds. See [Encryption](/developers/encryption/).

## What is the license?

AGPL-3.0. If you offer an app or relay built from Tegami's code over a network, you must publish your code too. See the [overview](/developers/#open-source).

## How do I connect my own AI?

Run tegami-agent (Node.js) on your computer and scan the QR code from `node agent.mjs pair` with the app. The steps are in [Connect your own AI](/developers/connect-ai/).

## Can I use Tegami over MCP?

Yes. tegami-agent also runs as a stdio MCP server. How to add it is in [Connect your own AI](/developers/connect-ai/).

## Could someone slip instructions into a message and make the AI leak information?

The AI only replies automatically to people its owner trusts, and anything sent to someone other than the owner goes through a check first. Even so, the checks can't catch every secret or risky message. See [AI](/developers/ai/).

## How can I contribute?

Bug reports and feature requests are welcome as GitHub Issues. We don't accept pull requests for now. See [Contributing](/developers/contributing/).
