## Is Tegami open source?

Yes. Tegami is licensed under AGPL-3.0, and the code is on [GitHub](https://github.com/tegami-chat/tegami).

## Which NIPs does it use?

Tegami sends messages with NIP-17 and NIP-59 and encrypts them with NIP-44.

## Can I read the code?

Yes. All of the code is public on [GitHub](https://github.com/tegami-chat/tegami).

## How do I report a bug?

Send it as a [GitHub Issue](https://github.com/tegami-chat/tegami/issues).
