コードは[GitHub](https://github.com/tegami-chat/tegami)で、AGPL-3.0のライセンスで公開しています。

現在は、不具合の報告と要望を[GitHubのIssue](https://github.com/tegami-chat/tegami/issues)で受け付けています。コードの取り込み（プルリクエスト）は受け付けていません。

セキュリティの問題を見つけたら、公開のIssueではなく、hello@tegami.chat にメールで知らせてください。
