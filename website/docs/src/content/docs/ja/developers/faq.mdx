## オープンソースですか？

はい。ライセンスはAGPL-3.0で、コードは[GitHub](https://github.com/tegami-chat/tegami)で公開しています。

## どのNIPを使っていますか？

メッセージをNIP-17とNIP-59で送り、NIP-44で暗号化します。

## コードを読めますか？

はい。コードはすべて[GitHub](https://github.com/tegami-chat/tegami)で公開しています。

## 不具合はどう報告しますか？

[GitHubのIssue](https://github.com/tegami-chat/tegami/issues)で報告してください。
