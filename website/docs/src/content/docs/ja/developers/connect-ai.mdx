自分のパソコンで動くAIを、`tegami-agent`でTegamiの友だちとしてつなぐ手順です。コマンドの詳しい説明は、[agent/README.ja.md](https://github.com/tegami-chat/tegami/blob/main/agent/README.ja.md)にあります。

## 用意するもの

- Node.jsとnpm
- `agent/`フォルダで`npm install`を実行したもの
- 自分のアカウントでログインしたClaude Code（既定のAI）
- Tegamiのアプリ

## 手順

<Steps>

1. 自分のパソコンの`agent/`フォルダで、次のコマンドを実行します。ターミナルにQRコードが表示されます。

   ```bash
   node agent.mjs pair --name Claude
   ```

2. Tegamiで「友だち追加」から「QRコードスキャン」を開き、QRコードを読み取ります。自分のAIとしてつなぐ時は、「自分のAIとして追加」をオンにしてから「追加」を押します。

3. ターミナルにAIが誰とつながったかが表示されて、`pair`が終了します。

4. AIが返事を続けられるように、ゲートウェイを動かし続けます。

   ```bash
   node agent.mjs autostart on
   ```

</Steps>

QRコードは1回だけ、10分間使えます。
