TegamiがNostrのどこを使い、どこを使っていないかをまとめたページです。

「提供中」などの状態の表示の意味は、[概要](/ja/developers/#状態の表示の意味)にあります。

## Nostrクライアントとの違い

<Aside type="tip" title="いま">

Nostrの規格上で動くメッセージアプリですが、SNSとしてのNostrクライアントではありません。アカウントにはNostrの鍵（secp256k1）を使い、メッセージはNIP-17の形式で送受信しますが、公開の投稿（kind 1）もプロフィールの公開（kind 0）も行いません。

</Aside>

## ほかのNostrアプリとのやり取り

<Aside type="tip" title="いま">

できません。Tegamiのアプリが接続するのは専用のリレー（`wss://relay.tegami.chat`）のみで、そのリレーもTegamiに登録された鍵でログインした接続からの封筒（NIP-59 の gift wrap。暗号化したメッセージを入れた入れ物）しか受け付けないためです。このように閉じた構成にしているのは、迷惑メッセージやなりすましを入口で止めるためであり、リレー側には登録制御、送信量の上限、通報、運営による鍵の停止機能を備えています。

</Aside>

<Aside type="caution" title="まだ">

「どのアプリでも同じ鍵で使える」というNostr本来の良さは、Tegamiにはありません。

</Aside>

<Aside type="note" title="これから">

-   <Badge text="検討中" variant="caution" /> 受信先として会社や学校などの独自のリレーを追加できる形、ほかのNostrアプリからのメッセージを表示できる形、Tegamiの定めるルールに同意したリレーだけを公式一覧に載せる形を比較しています。どれを採用するかはまだ決めていません。

</Aside>

## 使う部分と使わない部分

<Aside type="tip" title="いま">

| Nostrの要素 | Tegamiでの扱い |
| --- | --- |
| アカウント＝secp256k1の鍵ペア（npubとnsec） | 使う。電話番号もメールアドレスも使わない |
| イベント形式（id、pubkey、created\_at、kind、tags、content、sig）とSchnorr署名 | 使う。メッセージ、リレーへのログイン、HTTPエンドポイントへの署名まですべてこの形式 |
| リレー（WebSocketでイベントを預かり配信するサーバー） | 使う。ただし公開リレーではなく、Tegami専用のリレー1つのみ |
| 暗号化したDM（NIP-17、NIP-44、NIP-59） | 使う。メッセージングの土台 |
| 公開の投稿（kind 1）、フォロー（kind 3）、タイムライン | 使わない。SNSとしての機能は持たない |
| 公開のプロフィール（kind 0） | 使わない。名前は招待リンクで渡し、アイコンは友だちにだけ暗号化して届ける |
| リレーの一覧の公開（NIP-65のkind 10002、NIP-17のkind 10050） | 使わない。アプリはTegami専用のリレーにだけ接続する |
| Zap（ビットコインの投げ銭） | アプリでは使わない。公式アカウントでの受け取りのみ対応 |
| 古いDM（NIP-04） | 使わない。送り主と宛先がリレーに丸見えになるため |

このように、Nostrを「鍵で本人性を表し、署名した封筒をリレーに預ける」仕組みとして使っており、SNSとしての部分は取り入れていません。

</Aside>

<Aside type="note" title="これから">

-   <Badge text="検討中" variant="caution" /> ビットコインで自由にお金のやり取りができるようにしたいと考えています。アプリにZapを組み込むかどうかはまだ決めていません。

</Aside>

## 使っているNIP

メッセージはNIP-17とNIP-59で送り、NIP-44で暗号化します。リレーへのログインはNIP-42、期限つきのイベントはNIP-40、HTTPの署名はNIP-98です。公式アカウントの識別子にNIP-05、リレーの情報にNIP-11を使います。写真とファイルの保管にはBlossomを使います。公開の投稿のkind 1と、公開のプロフィールのkind 0は使いません。一覧は[技術仕様](/ja/developers/spec/)にあります。
