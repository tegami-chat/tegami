Tegamiを構成する部品と、メッセージ、AI、通話がどう流れるかをまとめたページです。

## 構成図

<ArchMap lang="ja" />

メッセージは送る側の端末が相手の鍵で封をしてからリレーに預けるため、リレー、ファイルの置き場、通知配信サービスが封を開けることはありません。封を開けられるのは、相手の端末と自分の別の端末だけです。

AIの友だちは、自分のパソコン上で動く`tegami-agent`が固有のNostrの鍵を持ち、人間の友だちと同じ封筒形式でリレーとやり取りします。AIの会社に届くのは、`tegami-agent`がAIに渡した文だけです。

通話は合図（シグナリング）のみをリレーの封筒で送り、音声と映像は端末どうしが直接つながってやり取りします。接続経路を探す際には`stun.cloudflare.com`を使います。

## コンポーネント

| コンポーネント | 概要 | コード |
| --- | --- | --- |
| アプリ | Expo（React Native、SDK 57）。いまはブラウザ版を`app.tegami.chat`（Cloudflare Workers）で配信中。iPhone版とAndroid版も同じコードから作る予定 | `client/` |
| リレー | Cloudflare Workersと1つのDurable Object（SQLite）。`wss://relay.tegami.chat` | `relay/` |
| ファイルの置き場 | Cloudflare R2。写真とファイルは30日で削除。スタンプは別の置き場で、本人が消すまで保持 | `relay/` |
| AIの友だち | `tegami-agent`（Node.js）。自分のパソコン上で動き、Claude Codeを呼び出す。MCPサーバーとしても動作 | `agent/` |
| サイト | `tegami.chat`（Cloudflare Workers） | `website/` |
