Tegamiがどんな部品でできていて、メッセージ、AI、通話がどこを通るのかを知りたい人のために、構成図と部品の一覧を示します。

## 封筒

Tegamiは、メッセージを封筒に入れてリレーに預けます。封筒とは、暗号化したメッセージを入れて、使い捨ての鍵で署名した外側のイベント（[kind](/ja/developers/spec/#用語) 1059）のことで、NIP-59ではgift wrapと呼びます。リレーに見えるのは封筒の外側だけです。中身を開けられるのは、宛先の鍵を持つ端末だけです。

## 構成図

<ArchMap lang="ja" />

図は左から右に読みます。左が自分の端末と自分のパソコン、中央がCloudflare上の部品、右が相手の端末と通知の会社です。線の種類は、図の右下にある凡例で見分けられます（暗号化した中身が通る線、アプリのコードを配る線、端末どうしが直接つながる線）。以下に、封筒、AI、通話の道すじを順に書きます。

メッセージは、送る側の端末が相手の鍵で封をしてからリレーに預けます。リレー、ファイルの置き場、通知を配る会社は、封を開けられません。封を開けられるのは、相手の端末と自分の別の端末だけです。

AIの友だちは、自分のパソコン上で動く`tegami-agent`が固有のNostrの鍵を持ち、人間の友だちと同じ封筒でリレーとやり取りします。AIの会社に届くのは、`tegami-agent`がAIに渡した文だけです。

通話は、合図（シグナリング）だけをリレーの封筒で送ります。音声と映像は、端末どうしが直接つながってやり取りします。接続の経路を探す時には`stun.cloudflare.com`を使います。
