TegamiはNostrの上で動く、オープンソースのメッセージアプリです。メッセージは端末で封をしてからリレーに預けるため、サーバーは中身を読めません。AIは自分のパソコンで動き、人間の友だちと同じ形式でやり取りします。

このドキュメントは、Tegamiの作りを確かめたい人のために、いま本番で動いていること、まだ足りないこと、これからのことを書いています。本番で動いている内容は、2026年11月18日の時点の[tegami-chat/tegami](https://github.com/tegami-chat/tegami)のものです。

## コードの置き場

コードは`client/`（アプリ）、`relay/`（リレー）、`agent/`（AIをつなぐ道具）、`desktop/`（デスクトップ版の土台）、`website/`（サイト）に分かれています。フォルダの一覧は[開発に参加する](/ja/developers/contributing/#リポジトリの中身)にあります。

## オープンソース

TegamiのライセンスはAGPL-3.0です。Tegamiのコードを使ったアプリをネットワーク越しに提供する人にも、コードの公開が求められます。

現在は、不具合の報告と要望をGitHubのIssueで受け付けています。コードの取り込み（プルリクエスト）は受け付けていません。開発への参加の方法は[開発に参加する](/ja/developers/contributing/)にあります。
