TegamiはNostrの上で動く、オープンソースのメッセージアプリです。メッセージはNIP-17で送ります。AIは自分のパソコンで動き、人間の友だちと同じ形式でやり取りします。

コードのライセンスはAGPL-3.0で、[GitHub](https://github.com/tegami-chat/tegami)で公開しています。
