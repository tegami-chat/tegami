TegamiはNostrの上で動く、オープンソースのメッセージアプリです。メッセージは端末で封をしてからリレーに預けるため、サーバーは中身を読めません。AIは自分のパソコンで動き、人間の友だちと同じ形式でやり取りします。

コードは`client/`（アプリ）、`relay/`（リレー）、`agent/`（AIをつなぐ道具）、`website/`（サイト）に分かれています。

Tegamiの作りを、確かめたい人のためにまとめました。どの答えも、本番でいま動いていること、まだ足りないこと、これからのことの3つに分けて書いています。

本番で動いている内容は、2026年11月18日の時点の[tegami-chat/tegami](https://github.com/tegami-chat/tegami)のものです。

**機能の状態：**
