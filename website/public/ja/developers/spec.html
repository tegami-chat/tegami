全体の構成
コンポーネント概要コード
アプリExpo（React Native、SDK 57）。いまはブラウザ版をapp.tegami.chat（Cloudflare Workers）で配信中。iPhone版とAndroid版も同じコードから作る予定client/
リレーCloudflare Workersと1つのDurable Object（SQLite）。wss://relay.tegami.chatrelay/
ファイルの置き場Cloudflare R2。写真とファイルは30日で削除。スタンプは別の置き場で、本人が消すまで保持relay/
AIの友だちtegami-agent（Node.js）。自分のパソコン上で動き、Claude Codeを呼び出す。MCPサーバーとしても動作agent/
サイトtegami.chat（Cloudflare Workers）website/
暗号仕様
使う場所方式
メッセージNIP-44 v2（secp256k1のECDH、HKDF、ChaCha20、HMAC-SHA256）。NIP-59でsealとgift wrapの二重に包む
秘密鍵の保管パスキーのPRF拡張（userVerification: required）で32バイトを取り、HKDF-SHA256でAES-GCM 256ビットの鍵にして暗号化。PRFが無い環境では、取り出せない設定のAES-GCMの鍵をIndexedDBに置く
写真とファイルファイルごとに新しいAES-GCM 256ビットの鍵を生成。鍵と、暗号化した後のデータのsha256は、暗号化したメッセージ（kind 15）の中で送信。スタンプは画像とアカウントの秘密鍵から鍵を導出
復旧コード28文字（140ビット）からHKDF-SHA256でバックアップ用の番号、AES-GCMの鍵、署名用のNostrの鍵の3つを作成
端末の引き継ぎ使い捨ての鍵宛てにNIP-44で暗号化し、NIP-40で10分の期限を付けた封筒を使用。使い捨ての秘密鍵はリンクの#より後ろにのみ含める
通知Web Push（VAPID）。中身は端末ごとにRFC 8291（aes128gcm）で暗号化
通話WebRTC（DTLS-SRTP）。合図はNIP-17の封筒（独自のkind 25050、期限1分）
リレーが受け付けるもの
  • WebSocketで受け付けるイベントはkind 1059（gift wrap）のみで、宛先（pタグ）が1つのもの。サイズ上限は128KB
  • 読み書きともにNIP-42でログインした鍵のみ許可。ログインの署名は10分以内のものが有効で、購読は1つの接続で20まで
  • 書き込めるのは登録済みで止められていない鍵だけ。読めるのは自分宛ての封筒のみで、1回の取得は500通まで、30日で削除。1人の受信箱は1万通まで、招待券なしで登録した人からの封筒は200通まで
  • 送る量の上限（トークンバケット）：IPアドレスごとに一度に300通（その後は1秒に5通）、鍵ごとに一度に120通（その後は1秒に3通）。1つのIPアドレスからの接続は50本まで

HTTPエンドポイント（写真、ファイル、スタンプの操作はkind 24242の署名、それ以外の書き込みはNIP-98の署名が必要。/crashだけは署名なし）：

エンドポイント役割
POST /register鍵の登録（招待券またはTurnstile）
PUT /upload、GETとHEAD /<sha256>写真とファイルの預け入れと取り出し。10MBまで
PUT /stamp、GETとHEADとDELETE /stamp/<sha256>スタンプ。1枚512KB、1人200枚まで
PUT、GET、DELETE /backup/<番号>復旧コードのバックアップ。64KBまで
POST、DELETE /push、GET /push/key通知の宛先の登録と、通知の公開鍵
POST /report通報
GET /stats週ごとの利用統計（公開）
POST /crashユーザーが許した時のみのエラー報告（保存しない）
POST /admin運営の鍵でのみ使える、鍵の停止などの管理操作
POST /register（AIの登録）公開済みAIの鍵の登録。本文に持ち主の署名（kind 25070）を付けて送ると、リレーはその鍵をAIとして覚え、1日の上限を数える
POST /turn公開済み通話の中継（TURN）の短い期限の認証情報を発行する。登録済みの鍵だけが使える。リクエストの内容は保存しない
DELETE /account公開済みアカウントの削除。リレーはその鍵の封筒、スタンプ、通知の宛先、登録を消す
Tegami独自のkind

いずれもgift wrapの中の暗号化された領域でのみ使用します。リレーに見えるのはkind 1059だけです。

kind中身
10100アイコン。友だちにだけ届ける
10101スタンプ一覧。自分の端末どうしで同期する
25050通話の合図（呼び出し、応答、終了、WebRTCの接続情報）
25060、25061AIへの下書き依頼と、AIからの下書き
10102公開済み友だち、グループ、ブロック、AIの設定の控え。自分の端末どうしで同期する
10103公開済みグループの状態（メンバー、名前、アイコン、管理者）。変更のたびに全体を送る
10104公開待ちAIをトークに招く依頼と、メンバー1人ずつの応答
25062、25063公開済みAIが持ち主の名前でメッセージを送りたいという依頼と、持ち主のアプリの答え
25064、25065公開済みAIが友だち一覧を求める依頼と、アプリが返す一覧
25066、25067公開待ちAIがほかの人のAIと話したいという依頼と、答え
25068公開済みQRコードでAIを友だちに追加する際の、1回限りのコードに対するAI側の応答
25069公開済み「すべてオフにする」。AIに止まるよう伝える
25070公開済み持ち主がAIの鍵に付ける署名（持ち主の証明）。アプリがAIへ渡す
