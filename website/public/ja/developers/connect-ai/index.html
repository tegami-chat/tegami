自分のAIをつなぐ

自分のパソコンで動くAIを、Tegamiの友だちとしてつなぐ手順を説明します。AIは自分専用のNostrの鍵を持ち、人と同じリレーと暗号でやり取りします。コマンドの詳しい説明は、agent/README.ja.mdにあります。

用意するもの

Section titled “用意するもの”
  • Node.jsとnpm
  • agent/フォルダでnpm installを実行したもの
  • 返事を書くAI。既定のClaude Codeを使うなら、インストールして自分のアカウントでログインしておきます
  • Tegamiのアプリ

手順

Section titled “手順”

  1. 自分のパソコンのagent/フォルダで、次のコマンドを実行します。ターミナルにQRコードが表示されます（--browserを付けるとブラウザでも開けます）。

  2. Tegamiで「友だち追加」から「QRコードスキャン」を開き、QRコードを読み取ります。自分のAIとしてつなぐ時は、「自分のAIとして追加」をオンにしてから「追加」を押します。

  3. ターミナルにAIが誰とつながったかが表示されて、pairが終了します。

  4. AIが返事を続けられるように、tegami-agentを動かし続けます。pairはつなぐだけなので、この手順が必要です。

QRコードは1回だけ、10分間使えます。

返事を書くAIを選ぶ

Section titled “返事を書くAIを選ぶ”

返事を書くAIは、既定でClaude Codeです。次のどれにも切り替えられます。

  • Claude Code
  • APIキー
  • ローカルモデル
  • 自作のプログラム

既定のAIプロバイダーです。Claude Codeに自分のアカウントでログインしてあれば、設定は要りません。ほかのAIプロバイダーから戻す時は、次のコマンドを実行します。

Anthropic、OpenAI、Gemini、OpenRouterのAPIキーで使えます。backendでAIプロバイダーとモデルを選び、keyでAPIキーを入れます。keyは、APIキーの入力を画面に出さずに求めます。

anthropicの部分は、openai、gemini、openrouterにも替えられます。

自分のパソコンで動くモデルです。Ollamaと、llama.cpp、LM Studio、vLLMに対応しています。

1行目がOllama、2行目がllama.cpp、LM Studio、vLLMです。

標準入力を読んで返事を出力する自作のプログラムも、watch --commandでつなげます。

招待リンクでつなぐ

Section titled “招待リンクでつなぐ”

アプリでQRコードを読み取らずに、招待リンクで手動でつなぐこともできます。1行目のinitでAIの招待リンクを表示し、Tegamiで開いてAIを友だちに追加します。そのあと、あなたの招待リンクを、2行目のaddに渡します。

MCPで使う

Section titled “MCPで使う”

tegami-agentは、stdioのMCPサーバーとしても動きます。次のコマンドでClaude Codeに追加すると、tegami_inboxでメッセージを読み、tegami_sendで送れます。/path/to/agent/agent.mjsの部分は、自分のパソコンでのagent.mjsの場所に書き換えます。

初期設定では、持ち主が書いた文だけをAIに見せます。
