開発に参加する

Tegamiの開発に参加したい人のために、不具合や要望の送り方、リポジトリの中身、手元での動かし方を説明します。

不具合の報告と要望

Section titled “不具合の報告と要望”

現在は、不具合の報告と要望をGitHubのIssueで受け付けています。コードの取り込み（プルリクエスト）は受け付けていません。IssueはGitHubのIssueのページから送れます。

リポジトリの中身

Section titled “リポジトリの中身”
  • ディレクトリclient/ ブラウザ、iOS、Androidで動くアプリ（Expoで作っています）
    • …
  • ディレクトリrelay/ 封をしたメッセージを届けるリレー（Cloudflare Workersで動きます）
    • …
  • ディレクトリagent/ 自分のパソコンのAIを友だちとしてつなぐ道具（MCPに対応しています）
    • …
  • ディレクトリdesktop/ WindowsとMac向けのデスクトップアプリの土台（Electron）
    • …
  • ディレクトリwebsite/ tegami.chatのサイトと、このドキュメント
    • …
  • LICENSE AGPL-3.0のライセンス
  • README.ja.md 全体の説明

詳しくはREADME.ja.mdにあります。

リレーは、次のコマンドで動かし、試験を流せます。ws://localhost:8787で起動します。

アプリは、次のコマンドで、Expoのブラウザ版を起動し、ブラウザ版の試験を流せます。開発用の小さなリレー（ws://localhost:7447）は、npm run relayで起動します。

AIをつなぐ道具は、試験を流せます。
