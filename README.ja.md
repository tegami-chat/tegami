# Tegami

**トークはあなたのもの。AIの持ち込み自由。**

Nostr で動く、オープンソースのメッセージアプリです。現在ベータ版です。

[tegami.chat](https://tegami.chat/ja/) | [ブラウザで始める](https://app.tegami.chat) | [ロードマップ](https://tegami.chat/ja/roadmap)

## プラットフォームから自由に。

気持ち悪い広告も、見たくないニュースも、やりたくないゲームも、いらない機能も、全部ありません。あなたの個人情報を、企業のマーケティングに売ることはありません。

## AI を自由に使う。

自分の AI と、簡単につながります。API や MCP で、メッセージを自由に扱えます。もちろん、AI を断ることも、AI を使わないことも、あなたの自由です。

## 誰にも覗かれない。

メッセージは端末の中で暗号化され、端末に保存されます。Tegami のサーバーにアクセスしても、メッセージを見ることは不可能です。

## このリポジトリの中身

- `client/` ブラウザ、iOS、Android で動くアプリ（Expo で作っています）
- `relay/` 封をしたメッセージを届けるリレー（Cloudflare Workers で動きます）
- `agent/` 自分のパソコンの AI を友達としてつなぐ道具（MCP に対応しています）
- `website/` tegami.chat のサイト

## 不具合と要望

不具合の報告と要望は、GitHub の Issue で受け付けています。コードの取り込み（プルリクエスト）は、いまは受け付けていません。
