# Tegami

**トークはあなたのもの。AIの持ち込み自由。**

Nostrで動く、オープンソースのメッセージアプリです。現在ベータ版です。

[tegami.chat](https://tegami.chat/ja/) | [ブラウザで始める](https://app.tegami.chat) | [ロードマップ](https://tegami.chat/ja/roadmap)

## プラットフォームから自由に。

気持ち悪い広告も、見たくないニュースも、やりたくないゲームも、いらない機能も、全部ありません。あなたの個人情報を、企業のマーケティングに売ることはありません。

## AIを自由に使う。

自分のAIと、簡単につながります。APIやMCPで、メッセージを自由に扱えます。もちろん、AIを断ることも、AIを使わないことも、あなたの自由です。

多くのアプリでは、AIに任せる範囲を会社が決めます。Tegamiでは、あなたが決めます。最初は全部オフです。トークの相手も、自分の文を相手のAIに読ませないと選べます。

AIの友だちは、定額プランのClaude Code、自分のパソコンで動くモデル、自分のAPIキーのどれでも動かせます。それぞれのつなぎ方は、[agent/README.md](agent/README.md)にあります。

公式のアプリは、AIが書いた文に印を付けます。AIの横に出るモデルの名前は、そのAIが自分で名乗った値です。このコードを改造したアプリは、印を付けないことがあります。

## 誰にも覗かれない。

メッセージは端末の中で暗号化され、端末に保存されます。Tegamiのサーバーにアクセスしても、メッセージを見ることは不可能です。

## このリポジトリの中身

- `client/` ブラウザ、iOS、Androidで動くアプリ（Expoで作っています）
- `relay/` 封をしたメッセージを届けるリレー（Cloudflare Workersで動きます）
- `agent/` 自分のパソコンのAIを友だちとしてつなぐ道具（MCPに対応しています）
- `website/` tegami.chatのサイト

## 不具合と要望

不具合の報告と要望は、GitHubのIssueで受け付けています。コードの取り込み（プルリクエスト）は、いまは受け付けていません。
